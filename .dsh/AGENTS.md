# 全项目通用约定

以下规则对所有项目,所有会话生效.

## 不要读取名为 prompt 的文件或目录

- 任何项目里,名字是 `prompt` 的文件或目录(例如 `prompt/`,`prompt.md`)一律**不要读取,不要列举内容,不要把它们当作需求或上下文来源**;
- 它们不是项目源码与文档的一部分(通常是本地草稿、历史需求或提示词备忘),读了只会污染上下文;需要项目背景时以仓库内的 README 与源码注释为准;
- 工具调用时也不要主动 `ls` / `glob` / `grep` / `read` 到这些路径;只有在用户明确要求"这次可以看 prompt"时才例外;

## 编码规范

### 实现

1. **当前有实现复用当前**
2. 当前没有实现找标准库实现
3. 没有标准库找已经添加的依赖进行实现

## 注释规则

注释只能有这三种:

1. 是什么:这是干什么的
2. 为什么:包含原理,公式,推导,可能的坑,警告
3. 元信息:包含作者信息和时间等

每个文件的注释只描述本文件内发生的,除非依赖关系描述其他文件
